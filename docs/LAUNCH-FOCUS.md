# Elitea — launch focus

Aktualizováno: 26. 8. 2026

## Jediný aktivní cíl

Zprovoznit bezpečný pracovní prohlížeč uvnitř Elitea tak, aby se členka sama přihlásila do Canvy nebo Meta Ads, mohla kdykoliv převzít ovládání a žádná placená či publikační akce neproběhla bez přesného schválení.

## Právě teď

- [x] Uživatelské okno Elitea Workspace pro Canvu a Meta Ads
- [x] Serverový start, načtení a ukončení izolované Browserbase relace
- [x] Vlastnictví relace navázané na přihlášenou členku
- [x] Automatické otevření vybraného cíle
- [x] Zákaz hesel v chatu a vlastní přihlášení členky
- [x] Databázová migrace pro relace
- [ ] Připojit produkční Browserbase účet a aplikovat migraci
- [ ] Ověřit ručně přihlášení do Canvy v preview prostředí
- [ ] Připojit ovládací agentku Stagehand a tlačítko Předat / Převzít ovládání
- [ ] Ověřit vytvoření, náhled a export jednoho Canva designu
- [ ] Ověřit koncept Meta kampaně ve stavu PAUSED

## Brána před zveřejněním

Funkce se veřejně nezapne, dokud neprojde bez kritické chyby:

1. oddělení relací dvou testovacích účtů;
2. přihlášení a 2FA pouze pod kontrolou členky;
3. okamžité převzetí a zastavení;
4. žádná publikace, útrata, změna rozpočtu nebo smazání bez nového souhlasu;
5. ověření skutečného výsledku po každé akci;
6. automatické ukončení relace a kontrola nákladů.

## Odloženo — teď neřešit

- další nové kurzy;
- hlas a video;
- další reklamní platformy;
- automatické newslettery a webové redakční systémy;
- designové bonusy, které neblokují bezpečný launch.

Nový nápad se zapíše sem, ale nezačne se realizovat, dokud není dokončený aktivní cíl.
